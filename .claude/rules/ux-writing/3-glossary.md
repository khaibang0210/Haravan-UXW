# UX Writing — Thuật ngữ

| Dùng | Không dùng |
|---|---|
| Trang quản trị | Admin, Haravan Admin, Dashboard |
| Cấu hình (menu) | Cài đặt, Setting |
| Thiết lập (động từ: thiết lập phí vận chuyển) | Setup, Config |
| Đơn hàng | Order, Đơn |
| Sản phẩm / Biến thể | Product / Variant, Phiên bản |
| Mã SKU / Mã vạch | Barcode (trong câu) |
| Chi nhánh | Kho (khi nói về địa điểm), Store, Location |
| Tồn kho | Inventory, Hàng tồn |
| Nhập dữ liệu / Xuất dữ liệu | Import / Export |
| Mã khuyến mãi | Mã giảm giá, Coupon, Voucher (trừ khi là tên của sàn) |
| Chương trình khuyến mãi | Campaign, Promotion |
| Nhà vận chuyển | Đối tác vận chuyển, Hãng ship, Carrier |
| Phương thức thanh toán / Cổng thanh toán | Payment method / Payment gateway |
| Kênh bán hàng | Sales channel |
| Nhân viên / Phân quyền | Staff / Role, Permission |
| Ứng dụng | App |
| Nhãn | Tag |
| Ghi chú | Note |
| Giao diện | Theme (trừ khi là tên của theme) |
| Cửa hàng | Shop (trong UI) |

**Trạng thái** (giữ đúng chữ trong hệ thống, viết hoa chữ đầu):
- Đơn hàng: `Lưu nháp`, `Hoàn tất`, `Đã hủy`
- Giao hàng: `Chưa giao`, `Đang giao`, `Đã giao`
- Thanh toán: `Chưa thanh toán`, `Đã thanh toán`, `Chờ xử lý`

> ponytail: danh sách trạng thái mới lấy từ docs, chưa đối chiếu UI thật. Cần bổ sung khi có export i18n.
